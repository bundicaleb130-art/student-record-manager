# Student Record Manager

A simple command-line student record management application built with Python.

## Features

- Add student records
- View student records
- Search for students by admission number
- Prevent duplicate admission numbers
- Validate required fields
- Save records permanently using JSON
- Automated unit testing

## Technologies

- Python 3
- JSON
- unittest
- Git
